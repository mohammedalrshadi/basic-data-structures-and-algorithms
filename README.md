## 📖 About This Repository

This repository documents my learning journey in **Data Structures and Algorithms (DSA)** using **C++**.

It was created for my **SCSE2103 – Data Structures and Algorithms** course at **Universiti Teknologi Malaysia (UTM)**, MJIIT, as well as for continuous learning, coding practice, and improving my problem-solving skills.

- Understand data structures and algorithms.
